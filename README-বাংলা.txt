FAHAD SHOP — ওয়েবসাইট চালানোর নিয়ম

১) ZIP ফাইলটি Extract/Unzip করুন।
২) Extract করা Fahad_Shop_Website ফোল্ডার খুলুন।
৩) index.html ফাইলটি Chrome বা অন্য কোনো ব্রাউজারে খুলুন।
৪) ওয়েবসাইট চালু হবে। ইন্টারনেট ছাড়াও এই নমুনা সাইটটি দেখা যাবে।

পণ্য ও দাম পরিবর্তন:
- index.html ফাইলটি Notepad বা অন্য Text Editor দিয়ে খুলুন।
- ফাইলের নিচের দিকে const items=[ ... ] অংশে পণ্যের নাম, ক্যাটাগরি, দাম ও ইমোজি পরিবর্তন করুন।
- পরিবর্তন করে Save দিন, তারপর ব্রাউজারে Reload করুন।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এটি Fahad Shop-এর চালানো যায় এমন প্রাথমিক ডেমো ওয়েবসাইট।
- অর্ডার সার্ভারে জমা হয় না; গ্রাহক অর্ডারের তথ্য কপি করে আপনাকে পাঠাতে পারবেন।
- বিকাশ/নগদে আসল অনলাইন পেমেন্ট, Facebook Page/Messenger সংযোগ, AI কাস্টমার সার্ভিস, অর্ডার ড্যাশবোর্ড বা ডেলিভারি ট্র্যাকিং এখনো যুক্ত নেই।
- এগুলো চালু করতে আলাদা সার্ভার/ডেটাবেস এবং পেমেন্ট ও মেসেজিং সংযোগ সেটআপ করতে হবে।

মোবাইলে:
- ZIP ফাইলটি Files/File Manager অ্যাপ দিয়ে Extract করুন।
- index.html-এ চাপ দিয়ে Chrome/Browser দিয়ে খুলুন।
- যদি ফোনে HTML ফাইল সরাসরি না খোলে, কম্পিউটারে Chrome দিয়ে খুলে পরীক্ষা করুন।
